# SlimCRM Sales Agent

Public configuration for a B2B Sales Agent focused on lead discovery and continuous follow-up. Human Sales owns consultation, demos, pricing, negotiation, and closing. Customer retention is out of scope until an approved CRM integration is available.

## Files

- `role/SALES_AGENT_CHECKLIST.md`: required actions for every shift.
- `role/SALES_AGENT_WORKFLOW.md`: proposal, approval, follow-up, handoff, and data lifecycle.
- `role/ROLE_CARD.md`, `role/JOB_DESCRIPTION.md`, `role/PEAS.md`: role definition and operating model.
- `.agents/skills/slimcrm-sales/SKILL.md`: entry point for using this configuration as an agent skill.
- `lich-lam-viec.md`: daily and weekly work schedule.
- `quyen-han.md`: approval and action boundaries.
- `brand/BRAND_VOICE.md`: public-safe writing guidance.
- `product/PRODUCT_PROFILE.md`: official product references; recheck before making a claim.
- `integrations/TOOLS.md`: connection configuration template.

## Start a shift

In the configured Agent workspace, ask: **“Bắt đầu ca SlimCRM Sales hôm nay và thực hiện công việc theo lịch.”** The Agent should follow the checklist and use only the private data and integrations supplied to that workspace.

## Privacy

This repository intentionally excludes prospect/customer records, activity history, private outputs, project memory, Taskboard data, account identifiers, and credentials. Keep those in an access-controlled workspace. No license is granted by this repository unless a license file is added.
